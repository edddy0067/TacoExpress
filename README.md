TacoExpress
 Descripción

**TacoExpress** es una aplicación móvil diseñada para optimizar el proceso de toma y gestión de pedidos en una taquería o restaurante. Su objetivo es agilizar la atención al cliente, reducir errores en las órdenes y mejorar la eficiencia operativa del negocio.

La aplicación permite a los usuarios consultar el menú digital, agregar productos al carrito, realizar pedidos y dar seguimiento al estado de sus órdenes en tiempo real, proporcionando una experiencia rápida, cómoda y moderna.

Características principales

* 📋 Menú digital con tacos, bebidas y complementos.
* 🛒 Carrito de compras para gestionar pedidos.
* 📦 Seguimiento del estado del pedido.
* 🔐 Registro e inicio de sesión de usuarios.
* 📜 Historial de pedidos realizados.
* 🔔 Notificaciones sobre actualizaciones del pedido.

Tecnologías utilizadas

* **Framework:** React Native
* **Lenguaje:** JavaScript
* **Arquitectura:** MVVM (Model-View-ViewModel)
* **Metodología Ágil:** Scrum
* **Control de versiones:** Git y GitHub

 Metodología de desarrollo

Para el desarrollo del proyecto se implementó la metodología **Scrum**, organizando el trabajo en sprints de dos semanas para facilitar la planificación, el seguimiento del progreso y la entrega continua de funcionalidades.

Objetivo del proyecto

Desarrollar una solución móvil que permita a las taquerías modernizar su proceso de atención al cliente mediante la digitalización de pedidos, contribuyendo a disminuir los tiempos de espera y mejorar la experiencia del usuario.
